### 1 — Erro no GitHub Actions: lock file não encontrado

**Usuário:**

> "Run actions/setup-node@v4
> (node:2179) [DEP0040] DeprecationWarning: The `punycode` module is deprecated. Please use a userland alternative instead.
> (Use `node --trace-deprecation ...` to show where the warning was created)
> Found in cache @ /opt/hostedtoolcache/node/22.23.4/x64
> Environment details
> /opt/hostedtoolcache/node/22.23.4/x64/bin/npm config get cache
> /home/runner/.npm
> Error: Dependencies lock file is not found in /home/runner/work/dsai-ap2--Delivery-/dsai-ap2--Delivery-. Supported file patterns: package-lock.json,npm-shrinkwrap.json,yarn.lock"
>
> deu esse erro quando criei um github action node.js no meu projeto

**Gemini:**

Identificou que o `actions/setup-node@v4` com `cache: 'npm'` exige um `package-lock.json` no repositório, e o projeto não tinha nem `package.json` nem lock file.

**Ações realizadas:**

1. **Criou `package.json`** — mínimo, com `"type": "module"` e script `test` que roda os 4 arquivos de teste:
   ```json
   {
     "name": "deliveryfast",
     "version": "1.0.0",
     "description": "Aplicativo web de delivery de comida — DeliveryFast",
     "private": true,
     "type": "module",
     "scripts": {
       "test": "node tests/checkout-validation.test.js && node tests/search.test.js && node tests/register-validation.test.js && node tests/profile-validation.test.js"
     }
   }
   ```

2. **Gerou `package-lock.json`** — via `npm install --package-lock-only` (sem dependências externas, só cria o lock file vazio exigido pelo `actions/setup-node`).

3. **Criou o workflow `.github/workflows/node.js.yml`** — roda em Node 20 e 22, faz `npm ci` e `npm test`.

4. **Verificou os testes localmente** — todos os 51 testes passando.

### 2 — Erro de YAML inválido no workflow

**Usuário:**

> o actions aponta esse erro agora: [Invalid workflow file: .github/workflows/node.js.yml#L2] You have an error in your yaml syntax on line 2

**Gemini:**

Ao inspecionar o arquivo, descobriu que o problema **não era só o caractere `—` (em dash)** no nome — o arquivo inteiro estava com **conflitos de merge não resolvidos** (marcadores `<<<<<<< HEAD`, `=======` e `>>>>>>>` misturando a versão criada pela interface do GitHub com a versão criada localmente).

**Ação realizada:**

Sobrescreveu o arquivo com a versão limpa e correta:

```yaml
name: Node.js CI - Testes Automatizados

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest

    strategy:
      matrix:
        node-version: [20.x, 22.x]

    steps:
      - name: Checkout do repositorio
        uses: actions/checkout@v4

      - name: Configurar Node.js ${{ matrix.node-version }}
        uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: 'npm'

      - name: Instalar dependencias
        run: npm ci

      - name: Executar testes
        run: npm test
```

## Decisões Técnicas

- **`"type": "module"`** no `package.json` — necessário porque os arquivos de teste usam `import` (ES Modules).
- **Sem dependências externas** — o projeto roda testes com Node.js puro, sem frameworks como Jest ou Mocha.
- **Node 20.x e 22.x** na matrix — versões LTS e Current suportadas; removida a 18.x que estava no template padrão do GitHub.
- **Conflitos de merge** — causados por criar o workflow pela interface do GitHub e também localmente; resolvidos sobrescrevendo com a versão final.
