### 2 — Correção de escopo

**Usuário:**

> na verdade era uma página carrinho, tem um emoji de um carrinho na parte de cima que não é clicavel, o que eu queria era que ele fosse clicavel e expandisse o layout do carrinho que fica no canto de baixo onde finaliza o pedido

**Gemini:**

Entendeu que a intenção era bem mais simples: **o ícone do header deve apenas abrir/destacar o widget flutuante existente**, sem criar uma nova página.

**Ações realizadas:**

#### 1. `src/index.html`
Substituído o `<div>` estático pelo `<button>` clicável:
```html
<button onclick="abrirCarrinho()"
  class="flex items-center gap-1 bg-red-700 hover:bg-red-800 px-3 py-1 rounded-full text-sm font-bold cursor-pointer transition"
  title="Ver carrinho">
  <span>🛒</span>
  <span id="cart-count">0</span>
</button>
```

#### 2. `src/components/cart.js`
Adicionada a função `abrirCarrinhoWidget()` ao final do arquivo:

| Situação | Comportamento |
|---|---|
| **Carrinho com itens** | Scroll suave até o widget + animação de pulso (3× scale 1.04 → 1) |
| **Carrinho vazio** | Exibe mensagem *"Seu carrinho está vazio"* por 2,5 segundos e some |

```javascript
export function abrirCarrinhoWidget() {
  let container = document.getElementById('cart-floating-widget');

  if (carrinho.length > 0 && container) {
    container.scrollIntoView({ behavior: 'smooth', block: 'end' });
    // animação de pulso
    container.style.transition = 'transform 0.15s ease';
    container.style.transform = 'scale(1.04)';
    setTimeout(() => { container.style.transform = 'scale(1)'; }, 200);
    setTimeout(() => { container.style.transform = 'scale(1.04)'; }, 350);
    setTimeout(() => { container.style.transform = 'scale(1)'; }, 500);
    return;
  }

  // carrinho vazio: mensagem temporária
  if (!container) {
    container = document.createElement('div');
    container.id = 'cart-floating-widget';
    container.className = 'fixed bottom-6 right-6 z-50 w-80 sm:w-96 shadow-2xl rounded-xl overflow-hidden transition-all';
    document.body.appendChild(container);
  }

  container.innerHTML = `
    <div class="bg-white border border-gray-200 p-5 rounded-xl shadow-lg text-center">
      <div class="text-4xl mb-2">🛒</div>
      <p class="text-gray-700 font-semibold text-sm">Seu carrinho está vazio</p>
      <p class="text-gray-400 text-xs mt-1">Adicione itens do cardápio para começar!</p>
    </div>
  `;

  setTimeout(() => {
    if (carrinho.length === 0) container.innerHTML = '';
  }, 2500);
}

window.abrirCarrinho = abrirCarrinhoWidget;
```

#### 3. `src/main.js`
Adicionado o import e o registro global:
```javascript
import { abrirCarrinhoWidget } from './components/cart.js';
window.abrirCarrinho = abrirCarrinhoWidget;
```

## Decisões Técnicas

- **Sem nova página:** a abordagem de expandir o widget existente é mais simples e consistente com a UX atual.
- **Animação por JS puro:** `transform: scale()` via `style` direto, sem adicionar classes Tailwind dinâmicas, para garantir compatibilidade com o CDN do Tailwind.
- **Mensagem temporária (2,5s):** evita deixar lixo no DOM quando o carrinho está vazio.
- **`window.abrirCarrinho` registrado em dois lugares** (`cart.js` e `main.js`): o de `cart.js` garante funcionamento mesmo que o `main.js` não tenha carregado ainda; o de `main.js` é o ponto oficial de registro para manter consistência com o padrão do projeto.
