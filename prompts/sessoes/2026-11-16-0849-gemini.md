## Decisões Técnicas

- **Arquivos volumétricos:** `profile.js` e `database.js` têm dezenas de milhares de linhas de código gerado pelo `gerador.py`. Para modificá-los sem perder o conteúdo, usou-se `Append: true` no `write_file` — o código funcional real fica nas últimas linhas.
- **IIFEs em ESM:** testes que usavam `(() => {})()` inline falhavam no loader ESM do Node 24. Reescritos com atribuição direta à variável `r` antes do `assert()`.
- **Funções globais via `window`:** padrão do projeto para chamar funções de componentes a partir de `onclick` inline no HTML gerado dinamicamente.
